# CUHKSZ Eats

CUHKSZ Eats 是由个人维护的校园餐饮信息静态网站，汇集香港中文大学（深圳）校内外餐饮地点、档口、菜品及相关照片，帮助访问者了解去哪里吃、有什么吃，以及实际观感和价格。

**希望它能为你在校园内外觅食时，提供一点实在的帮助。**

网站内容来自维护者本地的图片目录，并在构建时生成内容索引和去敏的响应式图片。原始照片不会提交到 Git 或公开部署；公开网站也不提供原图入口。

项目的程序代码、文档和测试保存在 `main` 分支，生成后的静态网站发布在 `gh-pages` 分支。关于环境准备、内容维护、本地预览、构建、测试与发布，请参阅[开发与部署指南](docs/development-and-deployment.md)。

## 非官方声明

CUHKSZ Eats 是由个人独立维护的非官方网站，与香港中文大学（深圳）及站内所列商户无隶属、授权或认可关系。内容仅记录特定时间的个人用餐与实拍信息，不代表校方或商户的实时菜单、价格及承诺，请以现场和官方信息为准。
